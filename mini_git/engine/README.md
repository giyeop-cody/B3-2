# ⚙️ Engine 패키지 기술 문서 (`mini_git/engine/`)

## 1. 개요 및 역할
`engine` 패키지는 순수 알고리즘 및 검색/비교 연산을 전담하는 **핵심 엔진 계층(Engine Layer)**입니다. 저장소 상태를 직접 관리하지 않고, 데이터를 전달받아 읽기 전용으로 연산을 수행합니다.

---

## 2. 모듈 구성
1. **`sorter.py` (`Sorter`)**: 직접 구현한 범용 병합 정렬 (Merge Sort).
2. **`graph.py` (`CommitGraph`)**: 위상 정렬(Kahn's Algo), 무방향 BFS 최단 경로, 조상 탐색.
3. **`index.py` (`InvertedIndex`)**: 사전 기반 역색인 고속 검색 엔진.
4. **`diff.py` (`LcsDiff`)**: LCS DP 기반 줄 단위 파일 차이 비교.

---

## 3. 핵심 알고리즘 및 자료구조 상세 분석

### 1) 병합 정렬 (`sorter.py`)
* **알고리즘**: Merge Sort (분할 정복).
* **복잡도**: 최선/평균/최악 $O(N \log N)$, 공간 복잡도 $O(N)$.
* **안정 정렬 보장**: 병합 루프에서 `left[i] <= right[j]` 부등호를 사용하여 동률 키값의 입력 순서 보존.
* **선정 이유 & 트레이드오프**: 파이썬 내장 정렬 API 금지 제약을 준수하고, Quick Sort의 $O(N^2)$ 위험을 방지하며 안정 정렬을 완벽 보장하기 위해 선택.

### 2) 위상 정렬 & 무방향 BFS (`graph.py`)
* **알고리즘**:
  * **위상 정렬**: Kahn's Algorithm (진입 차수 차감 및 Merge Sort 큐 재정렬).
  * **최단 경로**: 무방향 너비 우선 탐색(Undirected BFS) + 사전순 문자열 타이 브레이킹.
* **복잡도**: 위상 정렬 $O(V \log V + E)$, BFS 최단 경로 $O(V + E)$.
* **선정 이유 & 트레이드오프**:
  * 부모 커밋이 자식 커밋보다 항상 먼저 출력되도록 Kahn's Algorithm 적용.
  * 분기된 두 브랜치 간 경로 탐색을 위해 단방향 부모 간선을 무방향 간선으로 재정의하는 메모리 트레이드오프 수용.

### 3) 역색인 검색 (`index.py`)
* **자료구조**: 해시맵 기반 역색인 (`dict[word, set[commit_hash]]`).
* **복잡도**: 탐색 시간 $O(1)$, 공간 복잡도 $O(W \times C)$.
* **선정 이유 & 트레이드오프**: 커밋 누적 시 선형 탐색($O(N \times L)$)의 지연을 방지하기 위해 생성 시점에 단어 인덱싱을 수행하고 $O(1)$ 탐색 속도를 획득.

### 4) 파일 Diff (`diff.py`)
* **알고리즘**: LCS (Longest Common Subsequence) Dynamic Programming.
* **복잡도**: 시간 및 공간 $O(N \times M)$.
* **선정 이유 & 트레이드오프**: 외부 diff 라이브러리 없이 순수 DP로 구현하여 정확한 줄 단위 추가/삭제/공통 식별.
